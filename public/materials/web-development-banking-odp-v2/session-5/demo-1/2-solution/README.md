# Solusi: Runtime JavaScript

## Catatan Instruktur
- Node.js memungkinkan developer menguji logika pengolahan data, algoritma, dan perhitungan transaksi keuangan secara cepat langsung dari terminal tanpa overhead membuka browser.
- Pola deteksi lingkungan (`typeof window !== "undefined"` vs `typeof process !== "undefined"`) umum digunakan pada pustaka universal/isomorfik yang dapat berjalan di browser maupun server.
