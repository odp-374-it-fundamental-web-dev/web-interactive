# Starter: Runtime JavaScript

## Instruksi Latihan
Buka `runtime.js` dan jalankan menggunakan Node.js di terminal:
```bash
node runtime.js
```
Selesaikan tugas:
1. Cetak salam pembuka dan identitas modul ODP IT ke terminal.
2. Periksa versi Node.js yang aktif menggunakan `process.version`.
3. Demonstrasikan pemeriksaan lingkungan eksekusi (apakah sedang berjalan di Node.js atau browser).
