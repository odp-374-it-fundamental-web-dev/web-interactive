# Starter: Variables & Data Types

## Instruksi Latihan
Buka `variables.js` dan selesaikan tantangan:
1. Deklarasikan konstanta nama bank `BANK_NAME` menggunakan `const` dengan nilai `"PT Bank Negara Indonesia (Persero) Tbk"`.
2. Deklarasikan variabel saldo awal `saldo` menggunakan `let` dengan nilai `100000`.
3. Perbarui nilai `saldo` menjadi `150000` (demonstrasikan bahwa `let` mengizinkan re-assignment).
4. Buat variabel untuk masing-masing tipe data: `isAktif` (boolean), `catatan` (null), `nomorReferensi` (undefined).
5. Cetak nilai dan tipe data dari setiap variabel menggunakan `console.log(typeof ...)`.
