# Solusi: Variables & Data Types

## Catatan Instruktur
- Aturan *immutability* binding pada `const` mencegah *accidental reassignment* yang dapat memicu bug sulit dilacak dalam kalkulasi keuangan.
- Perhatikan bahwa `typeof null` mengembalikan `"object"`. Ini adalah bug historis JavaScript sejak versi pertama (1995) yang dipertahankan demi *backward compatibility*. Trainee perlu memahami ini agar tidak bingung saat memeriksa tipe data `null`.
