# Starter: Struktur Data (Objects & Arrays)

## Instruksi Latihan
Buka `structures.js` dan jalankan dengan Node.js:
```bash
node structures.js
```
1. Kelola array nominal transaksi `nominal = [25000, 50000, 75000]`.
2. Ubah item kedua (indeks `1`) dari `50000` menjadi `60000`.
3. Tambahkan nominal baru `10000` ke akhir array menggunakan method `push()`.
4. Buat objek `transaksi` dengan properti: `id`, `deskripsi`, `nominal`, dan `status`.
5. Tambahkan properti baru `waktu` ke dalam objek transaksi menggunakan dot notation.
