# Starter: Tabel Data Terstruktur

## Instruksi Latihan
Buka `index.html` dan perbaiki susunan tabel data rencana belajar:
1. Tambahkan elemen `<caption>` tepat setelah tag pembuka `<table>` dengan teks: "Rencana Pembelajaran Mingguan - BNI ODP IT".
2. Kelompokkan baris judul kolom di dalam elemen `<thead>`.
3. Ganti sel judul kolom dari `<td>` menjadi `<th scope="col">`.
4. Kelompokkan baris data isi di dalam elemen `<tbody>`.
5. Pastikan jumlah sel `<td>` pada setiap baris `<tr>` konsisten dengan jumlah kolom di `<thead>`.
