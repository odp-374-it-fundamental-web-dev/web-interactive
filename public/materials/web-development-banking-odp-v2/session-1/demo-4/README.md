# Demo 4: Tabel Data Terstruktur (Data Tables)

## 1. Overview
Demo ini mengajarkan pembuatan tabel data tabular yang aksesibel:
- Elemen inti `<table>`, `<caption>` (judul deskriptif tabel untuk pembaca layar).
- Pembagian struktural `<thead>`, `<tbody>`, dan opsional `<tfoot>`.
- Penggunaan header sel `<th scope="col">` untuk kolom dan `<th scope="row">` untuk baris.
- Sel data reguler `<td>`.
- Penegasan standar perbankan: Jangan pernah menggunakan `<table>` untuk tata letak halaman visual (page layout). Tabel hanya digunakan untuk data tabular relasional.

## 2. Learning Objectives
- Membangun tabel jadwal rencana belajar perbankan yang terstruktur secara semantik.
- Memahami fungsi atribut `scope` pada elemen `<th>` untuk navigasi screen reader.
- Memastikan tabel memiliki `<caption>` yang mendeskripsikan ringkasan data.
