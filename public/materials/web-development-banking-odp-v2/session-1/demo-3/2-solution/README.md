# Solusi: List & Struktur Semantik HTML5

## Catatan Instruktur
- Penggunaan elemen landmark seperti `<header>`, `<nav>`, `<main>`, `<section>`, dan `<footer>` memungkinkan pengguna tuna netra yang menggunakan screen reader untuk berpindah langsung ke bagian dokumen tertentu menggunakan tombol shortcut.
- Elemen `<main>` hanya boleh ada satu per halaman HTML untuk menandai konten unik halaman tersebut.
- Tag `<ol>` merepresentasikan relasi urutan logis/kronologis (langkah 1 harus mendahului langkah 2), sedangkan `<ul>` merepresentasikan kumpulan item tanpa urutan hierarkis.
