# Starter: List & Struktur Semantik HTML5

## Instruksi Latihan
Buka `index.html` dan refactor struktur berbasis `<div>` menjadi elemen semantik HTML5:
1. Ganti `<div class="header">` menjadi `<header>`.
2. Ganti `<div class="nav">` menjadi `<nav>`.
3. Bungkus area konten utama dengan elemen `<main>`.
4. Ganti `<div class="section">` menjadi `<section>` yang memiliki heading berjenjang.
5. Ubah daftar langkah belajar menjadi daftar terurut `<ol>` dengan elemen `<li>`.
6. Ubah daftar bidang minat menjadi daftar tak terurut `<ul>` dengan elemen `<li>`.
7. Ganti `<div class="footer">` menjadi `<footer>`.
