# Starter: Tautan & Gambar

## Instruksi Latihan
Buka `index.html` dan selesaikan tantangan path serta tautan:
1. Perbaiki tautan eksternal ke website resmi BNI agar menggunakan skema lengkap `https://` sehingga tidak terbaca sebagai path file lokal.
2. Tambahkan atribut keamanan `target="_blank"` dan `rel="noopener noreferrer"` pada tautan eksternal.
3. Buat tautan fragment `<a href="#keahlian">` yang mengarah ke elemen dengan atribut `id="keahlian"`.
4. Pasang gambar avatar dari subfolder relatif `assets/avatar.svg`.
5. Tambahkan atribut `alt="Foto profil Budi Santoso"` serta dimensi `width="120"` dan `height="120"`.
