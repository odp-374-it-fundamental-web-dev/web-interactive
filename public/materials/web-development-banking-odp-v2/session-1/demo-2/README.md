# Demo 2: Tautan (Links) & Gambar (Images)

## 1. Overview
Demo ini berfokus pada navigasi web dan penyertaan media:
- Tautan absolut (`https://...`) vs tautan relatif (`assets/avatar.svg` atau `kontak.html`).
- Tautan fragment internal (`#minat`) untuk navigasi dalam halaman yang sama.
- Atribut keamanan pada tautan eksternal (`target="_blank" rel="noopener noreferrer"`).
- Penyertaan gambar dengan `<img>`, void element, penentuan atribut `alt` yang deskriptif untuk aksesibilitas, serta dimensi `width` dan `height`.

## 2. Learning Objectives
- Membedakan URL eksternal absolut dan path berkas lokal relatif.
- Mengatasi tautan rusak akibat penulisan path yang keliru (`C:\Users\...` atau tidak menyertakan skema `https://`).
- Memasang gambar dengan teks alternatif (`alt`) yang bermakna bagi pengguna pembaca layar (*screen reader*).
