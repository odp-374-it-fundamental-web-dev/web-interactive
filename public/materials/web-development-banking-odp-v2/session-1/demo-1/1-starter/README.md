# Starter: Dokumen HTML Pertama & Anatomi Tag

## Instruksi Latihan
Buka `index.html` di VS Code dan perbaiki struktur dokumen sesuai `TODO` yang tersedia:
1. Tambahkan deklarasi `<!DOCTYPE html>` di baris paling awal.
2. Tambahkan tag root `<html lang="id">` dengan penutup `</html>`.
3. Lengkapi bagian `<head>` dengan `<meta charset="UTF-8">`, `<meta name="viewport" content="width=device-width, initial-scale=1.0">`, dan `<title>`.
4. Perbaiki urutan judul heading dari `h1` hingga `h3` secara berjenjang (jangan melompati jenjang heading).
5. Pasang tag penekanan semantik `<strong>` untuk teks penting dan `<em>` untuk penekanan intonasi.
6. Periksa hasil tampilan di browser menggunakan ekstensi VS Code Live Server atau buka langsung file `index.html`.
