# Solusi: Dokumen HTML Pertama & Anatomi Tag

## Catatan Instruktur
File `index.html` ini mendemonstrasikan implementasi dokumen HTML5 yang valid:
- `<!DOCTYPE html>` memberi tahu browser modern untuk merender halaman dalam mode *standards compliance* (bukan *quirks mode*).
- Atribut `lang="id"` membantu mesin pencari dan *screen reader* (aksesibilitas) mengenali bahasa konten Indonesia.
- Tag `<meta name="viewport" content="width=device-width, initial-scale=1.0">` memastikan rendering proporsional di layar perangkat mobile.
- Heading tersusun berjenjang dari `h1` (judul utama halaman) menuju `h2` (bagian konten), tidak melompati jenjang hierarki.
- Tag semantik `<strong>` dan `<em>` digunakan untuk makna penekanan, bukan sekadar gaya visual tebal/miring.
