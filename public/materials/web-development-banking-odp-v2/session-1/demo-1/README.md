# Demo 1: Dokumen HTML Pertama & Anatomi Tag

## 1. Overview
Demo ini membimbing peserta memahami struktur dasar dokumen HTML5 (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`), perbedaan opening tag vs closing tag, tag penutup mandiri (*void elements* seperti `<img>` dan `<meta>`), serta penggunaan tag teks dasar (`h1`–`h6`, `p`, `strong`, `em`).

## 2. Learning Objectives
- Menyusun anatomi dokumen HTML5 yang valid dan lengkap.
- Mengatur atribut bahasa (`lang="id"`) dan metadata viewport/charset.
- Menghindari kesalahan umum pemula (lupa closing tag, nesting tag yang keliru, dan penggunaan ekstensi ganda `.html.txt`).

## 3. Pedagogical Progression
1. **1-starter**: Dokumen tidak lengkap dengan tag yang salah bersarang, `<!DOCTYPE html>` hilang, dan instruksi `TODO` terstruktur.
2. **2-solution**: Dokumen HTML5 yang valid, rapi, dan mematuhi standar W3C.
