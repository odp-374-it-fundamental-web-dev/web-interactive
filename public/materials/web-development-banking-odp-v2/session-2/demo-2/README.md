# Demo 2: Jenis Input & Validasi HTML5

## 1. Overview
Demo ini mengeksplorasi berbagai tipe input dalam HTML5 serta atribut validasi bawaan browser:
- Tipe input teks (`text`), surel (`email`), angka (`number`), pilihan dropdown (`<select>` dan `<option>`), pilihan radio button (`type="radio"`), kotak centang (`type="checkbox"`), dan teks multiline (`<textarea>`).
- Atribut validasi deklaratif: `required`, `minlength`, `maxlength`, `min`, `max`.
- Pesan validasi otomatis dari browser (*bubble validation*) dan batasan penting: Validasi client-side adalah untuk UX/kenyamanan pengguna dan bukan pengganti validasi ketat di backend server perbankan.

## 2. Learning Objectives
- Memilih tipe input yang tepat agar memunculkan layout keyboard yang sesuai pada perangkat mobile.
- Menerapkan batasan validasi dasar tanpa perlu menulis script JavaScript tambahan.
- Mengelompokkan pilihan radio button menggunakan atribut `name` yang identik.
