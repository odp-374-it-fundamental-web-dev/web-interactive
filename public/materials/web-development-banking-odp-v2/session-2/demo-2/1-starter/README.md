# Starter: Jenis Input & Validasi HTML5

## Instruksi Latihan
Buka `index.html` dan lengkapi konfigurasi elemen form:
1. Jadikan input nama dan email wajib diisi (`required`).
2. Pasang batasan minimal 3 karakter (`minlength="3"`) pada nama lengkap.
3. Buat elemen `<select>` untuk topik pertanyaan dengan opsi awal kosong bertuliskan "-- Pilih Topik --" (`value=""`).
4. Buat dua opsi radio button untuk kategori akun ("Nasabah Perorangan" vs "Nasabah Institusi") dengan atribut `name="kategori"` yang sama.
5. Buat elemen `<textarea>` untuk pesan pertanyaan dengan atribut `rows="4"`, `required`, dan `minlength="10"`.
6. Coba tekan tombol Kirim saat form masih kosong atau diisi data tidak valid untuk melihat pesan kesalahan browser.
