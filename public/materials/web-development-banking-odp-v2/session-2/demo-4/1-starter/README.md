# Starter: Navigasi Terminal & Git Workflow CLI

## Instruksi Latihan
1. Buka terminal di folder ini.
2. Periksa posisi direktori aktif menggunakan `pwd` dan daftar berkas dengan `ls -la`.
3. Terdapat berkas `.env` yang memuat konfigurasi API internal latihan.
4. **Tantangan Keamanan**: Jangan biarkan berkas `.env` ini ter-commit ke Git!
5. Buat berkas `.gitignore` dan masukkan aturan untuk mengabaikan `.env`, `.DS_Store`, dan direktori `node_modules/`.
6. Jalankan skrip latihan `bash terminal-exercise.sh` untuk mensimulasikan workflow `git init`, `git add`, dan `git commit`.
