# Solusi: Navigasi Terminal & Git Workflow CLI

## Catatan Instruktur
- Berkas `.gitignore` harus dibuat dan dikonfigurasi **sebelum** melakukan `git add .`. Jika berkas rahasia terlanjur di-commit, menambahkan namanya ke `.gitignore` di kemudian hari tidak akan menghapusnya dari riwayat commit Git.
- Standar pesan commit korporat perbankan menggunakan format Conventional Commits:
  - `feat: add contact form with html5 validation`
  - `fix: resolve label for id mismatch in login form`
  - `docs: update project setup instructions in readme`
  - `chore: add gitignore for secret credentials and os cache`
- Riwayat commit yang rapi berfungsi sebagai jejak audit (*audit trail*) kepatuhan regulasi perbankan.
