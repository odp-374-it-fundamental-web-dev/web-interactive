# Starter: Anatomi Form & Hubungan Label-Input

## Instruksi Latihan
Buka `index.html` dan perbaiki masalah aksesibilitas serta struktur formulir:
1. Ganti teks petunjuk mengambang dengan elemen `<label>` yang sesungguhnya.
2. Pasang atribut `for` pada setiap `<label>` yang nilainya sama persis dengan `id` pada elemen input pasangannya.
3. Tambahkan atribut `name` pada input teks dan input email agar browser dapat menyusun payload form data.
4. Pastikan elemen tombol memiliki atribut `type="submit"`.
