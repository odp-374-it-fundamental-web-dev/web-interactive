# Starter: Perulangan & Tracing Eksekusi

## Instruksi Latihan
Buka `loops.js` dan jalankan dengan Node.js:
```bash
node loops.js
```
1. Iterasi array nominal `[100000, 250000, 50000, 75000]` menggunakan loop `for...of` dan hitung total jumlahnya.
2. Gunakan `continue` untuk melewati nominal yang bernilai minus atau nol.
3. Gunakan loop `while` untuk mensimulasikan percobaan otentikasi PIN (maksimal 3 kali percobaan salah sebelum akun diblokir).
