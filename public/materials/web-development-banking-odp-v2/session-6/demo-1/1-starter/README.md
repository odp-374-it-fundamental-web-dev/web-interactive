# Starter: Boolean Expressions & Truthy / Falsy

## Instruksi Latihan
Buka `boolean.js` dan jalankan dengan Node.js:
```bash
node boolean.js
```
1. Bandingkan hasil `0 == false` vs `0 === false`.
2. Evaluasi ekspresi logika saldo dan status akun menggunakan `&&` dan `||`.
3. Tuliskan fungsi sederhana `cekTruthy(nilai)` yang mengonversi nilai apa pun menjadi boolean menggunakan operator `Boolean(nilai)` atau `!!nilai`.
