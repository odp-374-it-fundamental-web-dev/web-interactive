# Starter: Flexbox untuk Navigasi & Komponen 1D

## Instruksi Latihan
Buka `index.html` dan `styles/style.css`:
1. Navigasi saat ini masih berupa link yang bertumpuk vertikal dan tidak teratur.
2. Pada selector `.navbar` di `styles/style.css`:
   - Pasang `display: flex`.
   - Atur `justify-content: space-between` untuk memisahkan brand dan daftar menu ke kedua sisi.
   - Atur `align-items: center` untuk meluruskan tinggi elemen.
   - Tambahkan `flex-wrap: wrap` dan `gap: 12px`.
3. Pada selector `.nav-links`:
   - Pasang `display: flex`.
   - Hilangkan bullet list dengan `list-style: none`.
   - Berikan `gap: 16px` antar item menu.
