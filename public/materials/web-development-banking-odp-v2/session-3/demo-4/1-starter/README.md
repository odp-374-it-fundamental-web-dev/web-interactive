# Starter: CSS Grid untuk Kartu & Layout 2D

## Instruksi Latihan
Buka `index.html` dan `styles/style.css`:
1. Pada selector `.grid-container` di `styles/style.css`:
   - Pasang `display: grid`.
   - Gunakan `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))`.
   - Berikan jarak antar kartu `gap: 20px`.
2. Hiasi elemen `.card` dengan background putih, border `1px solid #CBD5E1`, padding `20px`, dan `border-radius: 8px`.
3. Uji responsivitas di browser: perkecil jendela browser dari lebar 1200px ke 768px dan 375px. Amati bagaimana kolom kartu otomatis berganti dari 3 menjadi 2 lalu 1 kolom secara mulus.
