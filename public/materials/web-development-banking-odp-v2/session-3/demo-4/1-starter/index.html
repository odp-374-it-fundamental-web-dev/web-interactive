Modul Rekayasa Perangkat Lunak ODP IT

Kartu di bawah saat ini masih bertumpuk vertikal satu per satu:

01. Web Fundamentals

Struktur dokumen standar HTML5, semantik landmark, dan pemisahan arsitektur web platform.

02. Forms & Git CLI

Validasi client-side, pengamanan pengiriman POST, dan audit trail Version Control perbankan.

03. CSS Layout Modern

Box model border-box, Flexbox navigasi 1D, dan CSS Grid responsif fluid 2D.

04. Bootstrap 5.3 Portal

Integrasi komponen UI siap pakai via CDN dan adaptasi breakpoint mobile-first.

05. JavaScript Logika

Kalkulasi presisi transaksi keuangan, konversi tipe eksplisit, dan struktur object/array.

06. Asynchronous API

Pengambilan data cuaca real-time Open-Meteo menggunakan fetch dan async/await.
