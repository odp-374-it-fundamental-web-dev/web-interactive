# Starter: CSS Syntax, Pemasangan & Specificity

## Instruksi Latihan
Buka `index.html` dan `styles/style.css`:
1. Hubungkan `styles/style.css` ke `index.html` menggunakan elemen `<link rel="stylesheet">` di dalam `<head>`.
2. Hapus inline style dan internal style yang berantakan pada `index.html`.
3. Di dalam `styles/style.css`, atur selector elemen `h1` dengan warna navy perbankan `#183153`.
4. Berikan kelas `.highlight` dengan warna oranye `#F05A22`.
5. Buat pseudo-class `a:hover` dan `a:focus-visible` agar tautan memiliki indikator interaksi visual yang jelas.
