# Solusi: Komponen Bootstrap (Navbar, Card, Button, Alert)

## Catatan Instruktur
- Penggunaan kelas komponen Bootstrap (`.navbar`, `.card`, `.alert`, `.btn`) memberikan konsistensi visual di seluruh aplikasi enterprise tanpa memerlukan ratusan baris CSS custom.
- Atribut `role="status"` pada `.alert` memberi tahu screen reader bahwa konten tersebut adalah pengumuman dinamis yang penting namun tidak memutus fokus pengguna secara agresif.
- Kelas form `.form-label` dan `.form-control` menyediakan padding, warna border, dan efek *focus glow* halus yang sudah memenuhi kontras aksesibilitas.
