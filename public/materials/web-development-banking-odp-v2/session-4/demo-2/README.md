# Demo 2: Komponen Bootstrap (Navbar, Card, Button, Alert)

## 1. Overview
Demo ini berfokus pada perakitan komponen UI siap pakai bawaan Bootstrap 5.3:
- **Navbar**: `.navbar`, `.navbar-expand-lg`, `.navbar-dark`, `.bg-dark`, `.navbar-brand`, `.navbar-nav`, `.nav-link`.
- **Card**: `.card`, `.card-header`, `.card-body`, `.card-title`, `.card-text`.
- **Alert**: `.alert .alert-info`, `.alert-success`, dilengkapi atribut aksesibilitas `role="status"` atau `role="alert"`.
- **Button Variants**: `.btn .btn-primary`, `.btn-secondary`, `.btn-outline-primary`.
- **Form Controls**: `.mb-3`, `.form-label`, `.form-control`, `.form-select`.

## 2. Learning Objectives
- Merakit antarmuka web perbankan yang profesional dalam hitungan menit menggunakan komponen standar.
- Menjaga kepatuhan aksesibilitas: Tetap memasangkan `<label class="form-label" for="...">` pada input Bootstrap.
- Menggunakan komponen alert dengan atribut ARIA `role="status"` yang ramah pembaca layar.
