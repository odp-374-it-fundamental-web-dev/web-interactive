# Starter: Komponen Bootstrap (Navbar, Card, Button, Alert)

## Instruksi Latihan
Buka `index.html`:
1. Navigasi saat ini masih berupa tag HTML unstyled. Tambahkan kelas Bootstrap:
   - `<nav class="navbar navbar-expand-lg navbar-dark bg-dark">`
   - Brand: `<span class="navbar-brand">BNI ODP IT</span>`
   - Daftar link: `<ul class="navbar-nav">` dan tiap link `<a class="nav-link">`.
2. Ubah div notifikasi menjadi komponen alert: `<div class="alert alert-info" role="status">`.
3. Bungkus kartu informasi rekening ke dalam struktur Bootstrap Card:
   - `<div class="card">`
   - `<div class="card-body">`
   - Judul `<h3 class="card-title">` dan teks `<p class="card-text">`.
4. Beri gaya pada form menggunakan `.form-label` dan `.form-control`.
