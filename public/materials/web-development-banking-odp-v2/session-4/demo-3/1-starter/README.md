# Starter: Sistem 12 Kolom Grid Bootstrap

## Instruksi Latihan
Buka `index.html`:
1. Saat ini kartu modul diletakkan tanpa pembungkus baris (`.row`) dan tanpa kelas grid kolom, sehingga layout berantakan.
2. Tambahkan pembungkus `<div class="row g-3">` di dalam `.container`.
3. Bungkus setiap kartu ke dalam div kolom responsif:
   `<div class="col-12 col-md-6 col-lg-4">`.
4. Uji di browser: perkecil lebar layar ke 375px (1 kolom), 768px (2 kolom), dan 1200px (3 kolom).
