Modul Pelatihan IT Perbankan

Galeri kartu menggunakan hierarki Bootstrap Grid 12 kolom (col-12 col-md-6 col-lg-4 dengan gutter g-3):

Modul 1: Web Standards

Arsitektur HTTP/HTTPS, dokumen HTML5 semantik, dan struktur data tabel.

Modul 2: Forms & Git

Validasi client-side, pengiriman form aman, dan version control audit trail.

Modul 3: CSS Layout

Box Model border-box, Flexbox navigasi 1D, dan CSS Grid 2D auto-fit.

Modul 4: Bootstrap Portal

Perakitan UI responsif dengan 12-column grid dan komponen standar.

Modul 5: JS Fundamentals

Logika transaksi, presisi keuangan IDR, dan manipulasi struktur data.

Modul 6: Async & APIs

Pengambilan data real-time via Fetch API dan pengelolaan Promise.
